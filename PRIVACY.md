# CaptureView Privacy Policy

[日本語](#japanese)

Last updated: September 1, 2026

CaptureView processes video and audio locally on the user's Windows device for
live monitoring.

## Camera and microphone access

- Camera access is used to receive video from the capture device selected by
  the user.
- Microphone access is used to receive audio from the input device selected by
  the user and play it through the selected output device.
- The Microsoft Store version may display Windows camera and microphone
  permission prompts when these features are first used.

CaptureView does not record, stream, upload, sell, or otherwise transmit
captured video or audio. It contains no advertising, analytics, telemetry, or
user-account functionality.

## Local application data

Settings and diagnostic logs are stored locally under:

```text
%LOCALAPPDATA%\CaptureView\
```

The settings file may contain Windows device identifiers, selected video
format, window position, and viewer preferences. Logs may contain device
counts, operational messages, and error codes. They do not contain captured
video or audio.

MSIX uninstallation does not remove this directory. Users can reset or remove
CaptureView's local data by deleting the directory manually after closing the
application.

CaptureView does not send these files to the developer. A user may choose to
attach relevant log excerpts when reporting an issue on GitHub.

## Contact

Questions and privacy-related requests can be submitted through the public
[CaptureView GitHub repository](https://github.com/hine/capture-viewer/issues).

# CaptureView プライバシーポリシー

最終更新日：2026年9月1日

CaptureViewは、ライブモニタリングのため、ユーザーのWindows端末上で映像と
音声をローカル処理します。

## カメラとマイクへのアクセス

- カメラアクセスは、ユーザーが選択したキャプチャデバイスから映像を受け取る
  ために使用します。
- マイクアクセスは、ユーザーが選択した入力デバイスから音声を受け取り、選択
  した出力デバイスで再生するために使用します。
- Microsoft Store版では、これらの機能を初めて使用するときにWindowsがカメラと
  マイクのアクセス許可を求める場合があります。

CaptureViewは、取得した映像や音声の録画、配信、アップロード、販売、その他の
外部送信を行いません。広告、アクセス解析、テレメトリ、ユーザーアカウント機能
も備えていません。

## ローカルのアプリケーションデータ

設定と診断ログは、次の場所にローカル保存されます。

```text
%LOCALAPPDATA%\CaptureView\
```

設定ファイルには、Windowsのデバイス識別子、選択した映像フォーマット、
ウィンドウ位置、表示設定などが含まれる場合があります。ログにはデバイス数、
動作メッセージ、エラーコードなどが含まれる場合があります。取得した映像や
音声は含まれません。

MSIXをアンインストールしても、このフォルダーは削除されません。CaptureViewを
終了した後、このフォルダーを手動で削除することで、ローカルデータをリセット
または削除できます。

CaptureViewがこれらのファイルを開発者へ送信することはありません。ユーザーは
GitHubで問題を報告する際に、必要なログの一部を任意で添付できます。

## お問い合わせ

質問やプライバシーに関する依頼は、公開
[CaptureView GitHubリポジトリ](https://github.com/hine/capture-viewer/issues)
から送信できます。
